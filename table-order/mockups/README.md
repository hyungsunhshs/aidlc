# 테이블오더 서비스 Mockup

User Story 기반으로 제작된 HTML mockup 페이지입니다.

## 파일 목록

| 파일 | 설명 | 대상 User Stories |
|------|------|-------------------|
| `customer-app.html` | 고객용 주문 앱 | US-C01 ~ US-C13 |
| `admin-app.html` | 관리자용 대시보드 | US-A01 ~ US-A19 |

## 실행 방법

브라우저에서 HTML 파일을 직접 열어서 확인할 수 있습니다:

```bash
# macOS
open mockups/customer-app.html
open mockups/admin-app.html

# Windows
start mockups/customer-app.html
start mockups/admin-app.html

# Linux
xdg-open mockups/customer-app.html
xdg-open mockups/admin-app.html
```

## 고객용 앱 (customer-app.html)

### 구현된 화면
1. **주문 시작 화면** (US-C01)
   - "주문 시작하기" 버튼
   - 세션 시작 플로우

2. **메뉴 화면** (US-C02, US-C03, US-C04)
   - 카테고리 탭 (전체, 메인, 사이드, 면류, 음료, 디저트)
   - 메뉴 카드 그리드 (이미지, 이름, 설명, 가격)
   - "담기" 버튼 (44x44px 터치 영역)

3. **장바구니 화면** (US-C05 ~ US-C09)
   - 담긴 메뉴 목록
   - 수량 조절 (+/- 버튼)
   - 메뉴 삭제
   - 장바구니 비우기
   - 총 금액 표시
   - "주문하기" 버튼

4. **주문 완료 모달** (US-C10, US-C11, US-C12)
   - 주문 번호 표시
   - 5초 카운트다운
   - 자동 메뉴 화면 리다이렉트

5. **주문 내역 화면** (US-C13)
   - 주문 목록 (시간순)
   - 주문 상태 (대기중/준비중/완료)
   - 주문 상세 정보

### UI/UX 특징
- 터치 친화적 버튼 (최소 44x44px)
- 명확한 시각적 피드백
- 카드 형태의 메뉴 레이아웃
- 플로팅 장바구니 버튼

## 관리자용 앱 (admin-app.html)

### 구현된 화면
1. **로그인 화면** (US-A01, US-A02, US-A03)
   - 매장 식별자, 사용자명, 비밀번호 입력
   - 로그인 버튼

2. **주문 현황 대시보드** (US-A04 ~ US-A07)
   - 통계 카드 (활성 테이블, 대기 주문, 준비 중, 오늘 매출)
   - 테이블별 카드 그리드
   - 새 주문 알림 (애니메이션)
   - 주문 상태별 색상 구분
   - 주문 상세 모달 (상태 변경)

3. **테이블 관리** (US-A08 ~ US-A12)
   - 테이블 목록
   - 설정 상태 표시
   - 초기 설정/재설정 버튼
   - 이용 완료 버튼
   - 과거 내역 버튼

4. **메뉴 관리** (US-A15 ~ US-A19)
   - 메뉴 테이블 뷰
   - 메뉴 추가 버튼
   - 수정/삭제 버튼

5. **매장 정보** (US-A13, US-A14)
   - 매장 기본 정보 표시
   - 정보 수정 버튼

### UI/UX 특징
- 사이드바 네비게이션
- 그리드 형태의 테이블 대시보드
- 새 주문 시 pulse 애니메이션
- 직관적인 상태 색상 코딩
- 확인 팝업 (삭제, 이용 완료)
