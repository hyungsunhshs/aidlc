# 한국어 응답 가이드라인

## 언어 규칙

- 모든 응답은 한국어로 작성한다
- 기술 용어(technical terms)는 영어 원문을 유지한다

## 기술 용어 범위

다음 항목은 영어로 유지한다:

- 프로그래밍 언어 키워드 및 구문 (예: `function`, `class`, `import`)
- 프레임워크 및 라이브러리 이름 (예: React, Spring, Node.js)
- API 명칭 및 HTTP 메서드 (예: GET, POST, REST API)
- 파일명, 변수명, 함수명
- CLI 명령어 및 옵션
- 오류 메시지 및 로그 출력
- 설정 파일 키 값 (예: `package.json`, `tsconfig.json` 내 속성)

## 적용 예시

- 올바른 예: "이 `component`는 `props`를 통해 데이터를 전달받습니다."
- 올바른 예: "`npm install` 명령어를 실행하세요."
- 잘못된 예: "이 구성요소는 속성들을 통해 자료를 전달받습니다." (불필요한 번역)

## 문서화 규칙

- 코드 주석: 한국어 또는 영어 모두 허용 (기존 코드베이스 스타일을 따른다)
- 커밋 메시지: 기존 프로젝트 관례를 따른다
- README 및 문서: 대상 독자에 맞춰 작성한다
