# User Personas

## Overview
테이블오더 서비스의 주요 사용자 페르소나를 정의합니다.

---

## Persona 1: 고객 (Customer)

### 기본 정보
| 항목 | 내용 |
|------|------|
| **이름** | 김민수 (대표 페르소나) |
| **연령대** | 전 연령대 (10대 ~ 70대) |
| **기술 수준** | 다양함 (스마트폰 기본 사용 가능 ~ 디지털 네이티브) |
| **역할** | 매장 방문 고객 |

### 특성
- **다양한 연령대**: 어린이부터 노년층까지 모든 연령이 사용
- **다양한 기술 수준**: 디지털 기기 사용 능숙도가 다양함
- **목적 중심**: 빠르고 쉽게 음식을 주문하고 싶음
- **인내심 제한**: 복잡한 과정에 쉽게 좌절할 수 있음

### 목표 (Goals)
1. 메뉴를 쉽게 탐색하고 원하는 음식 찾기
2. 직원 호출 없이 편하게 주문하기
3. 주문 현황을 실시간으로 확인하기
4. 추가 주문을 간편하게 하기

### 니즈 (Needs)
- **직관적인 UI**: 설명 없이도 사용 방법을 알 수 있어야 함
- **큰 터치 영역**: 실수로 잘못 누르지 않도록 충분한 크기
- **명확한 피드백**: 버튼 클릭, 주문 완료 등에 대한 명확한 반응
- **빠른 응답**: 화면 전환, 주문 처리가 빨라야 함

### 불편함 (Pain Points)
- 복잡한 메뉴 구조로 원하는 메뉴를 찾기 어려움
- 주문이 제대로 들어갔는지 불안함
- 현재까지 주문한 금액을 알기 어려움
- 직원을 부르기가 번거로움

### 사용 시나리오
1. 테이블에 앉아서 태블릿의 "주문 시작" 버튼을 누름
2. 메뉴를 카테고리별로 탐색
3. 원하는 메뉴를 장바구니에 담음
4. 장바구니에서 수량 조절 후 주문 확정
5. 식사 중 추가 주문 진행
6. 주문 내역에서 현재까지 주문 확인

## Persona 2: 관리자 (Admin)

### 기본 정보
| 항목 | 내용 |
|------|------|
| **이름** | 박사장 (대표 페르소나) |
| **연령대** | 30대 ~ 60대 |
| **기술 수준** | 기술 초보자 (스마트폰 기본 사용 가능) |
| **역할** | 매장 사장/매니저 |

### 특성
- **기술 초보**: 복잡한 시스템 사용 경험 적음
- **바쁜 환경**: 여러 업무를 동시에 처리해야 함
- **실수 최소화**: 주문 실수나 누락이 매출에 직접 영향
- **빠른 판단 필요**: 피크 시간대에 빠른 의사결정 필요

### 목표 (Goals)
1. 들어오는 주문을 실시간으로 확인하고 관리
2. 테이블별 주문 현황 파악
3. 메뉴 정보를 쉽게 등록/수정
4. 테이블 이용 완료 후 정산 처리

### 니즈 (Needs)
- **한눈에 보이는 대시보드**: 복잡한 탐색 없이 현황 파악
- **명확한 알림**: 새 주문 시 눈에 띄는 알림
- **간단한 조작**: 클릭 몇 번으로 주요 작업 완료
- **실수 방지**: 중요 작업 전 확인 팝업

### 불편함 (Pain Points)
- 주문이 많을 때 놓치는 주문 발생
- 테이블별 주문 현황 파악이 어려움
- 메뉴 가격 변경이 번거로움
- 테이블 정산 시 주문 내역 확인이 어려움

### 사용 시나리오
1. 영업 시작 시 관리자 화면 로그인
2. 대시보드에서 테이블별 주문 현황 모니터링
3. 새 주문 들어오면 확인 후 주방에 전달 (상태 변경)
4. 고객 퇴장 시 테이블 "이용 완료" 처리
5. 메뉴 품절 시 메뉴 관리에서 수정
6. 매장 정보나 테이블 설정 변경

## Persona Summary

| 페르소나 | 주요 특성 | 핵심 니즈 | UI 고려사항 |
|----------|-----------|-----------|-------------|
| **고객** | 전 연령대, 다양한 기술 수준 | 직관적, 빠른 주문 | 큰 버튼, 명확한 피드백, 단순한 흐름 |
| **관리자** | 기술 초보자, 바쁜 환경 | 한눈에 현황 파악, 간단한 조작 | 대시보드 형태, 명확한 알림, 확인 팝업 |

## Design Implications

### 고객용 앱 설계 원칙
1. **최소한의 단계**: 주문까지 3단계 이내
2. **큰 터치 타겟**: 최소 44x44px 버튼
3. **명확한 시각적 계층**: 중요한 정보 강조
4. **즉각적인 피드백**: 모든 액션에 시각적 반응
5. **에러 방지**: 실수 가능성 최소화

### 관리자용 앱 설계 원칙
1. **대시보드 중심**: 한 화면에서 전체 현황 파악
2. **색상 코딩**: 상태별 명확한 색상 구분
3. **큰 클릭 영역**: 바쁜 상황에서도 쉽게 클릭
4. **확인 절차**: 삭제, 완료 등 중요 작업 전 확인
5. **실시간 업데이트**: 새로고침 없이 자동 갱신
